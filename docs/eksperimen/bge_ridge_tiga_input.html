BGE-M3 frozen → Ridge dengan tiga input

Jalankan di Colab · Notebook source · Bukti teknis dan batas pengujian.

Eksperimen ini menggunakan soal, jawaban_referensi, dan response_text, dengan satu target guru rater0–100. BGE tetap frozen. Tujuannya menguji pembaca Ridge pada representasi acuan, lalu membandingkan prediksi test dengan S2 MLP tiga input. Belum ada hasil penelitian dari notebook baru ini.

Kontrak fitur dan parameter

Checkpoint BAAI/bge-m3, revision 5617a9f61b028005a4858fdac845db406aefb181. Resep single-sequence mengikuti E21: konteks soal/referensi maksimal192token, soal maksimal64, window1024, overlap128, batch4. Mean CLS antar-window kemudian L2 menghasilkan1024komponen. Encoder memakai eval, no_grad dan requires_grad=False. Teks test dapat diekstrak karena encoder tidak memperbarui parameter atau mempelajari statistik korpus.

Grid alpha 0.01, 0.1, 1, 10, 100 ditetapkan sebelum run, mengikuti diagnosis terdahulu. Ridge menggunakan intercept, solver Cholesky, target asli0–100, fitur L2 tanpa StandardScaler. Perhitungan head float64; fitur tersimpan float32 seperti acuan. Tidak ada learning rate, dropout, epoch atau pemilihan seed untuk Ridge. Pengaturan token dan grid alpha adalah rancangan eksperimen yang dikendalikan, bukan rekomendasi angka optimal dari paper.

Seleksi, OOF dan test

  1. Gunakan enam header dataset yang sama dengan E21–E32. Kelompok email/duplikat tidak menyeberang partisi. Split memakai128kandidat GroupShuffleSplit seed2026, memilih proporsi baris terdekat80:20 tanpa label; lima GroupKFold di development.
  2. Setiap outer fold memilih alpha menggunakan empat blok fold lain saja. Prediksi outer validation digabung menjadi nested OOF. Ini mengevaluasi prosedur seleksi, bukan satu alpha final yang dipilih memakai outer validation.
  3. Pilih alpha final melalui pooled RMSE lima fold development. Jika seri, pilih alpha lebih kecil. Skor yang dipakai seleksi ini tidak disebut evaluasi independen.
  4. Simpan kontrak alpha, fit model baru pada seluruh development, simpan koefisien, lalu prediksi test. Test tidak dipakai memilih alpha.

Test historis sudah dievaluasi pada keluarga eksperimen sebelumnya. Karena pilihan penelitian berikutnya dipengaruhi hasil lama, perbandingan ini bersifat retrospektif. Prosedur baru tidak menjadikan holdout lama sebagai test baru yang belum pernah dilihat. Jumlah240/60 hanya berlaku ketika dataset300 dan kelompoknya sama; notebook melaporkan jumlah aktual.

Cara membandingkan dengan S2 E21–E32

Bandingkan prediksi test Ridge dengan prediksi test S2 pada jawaban yang sama setelah memeriksa ketiga teks, skor guru, keanggotaan test dan fold. ID baris saja tidak membuktikan kesamaan data. Skor OOF Ridge dari diagnosis lama tidak boleh disejajarkan dengan skor test S2. Workbook baru menyimpan seluruh informasi pencocokan; angka S2 lama tidak diisi dari ingatan atau disalin ke notebook ini.

E22 memakai format token konteks berbeda; selisihnya belum mengisolasi perubahan head. E29/E31 mempunyai LR MLP S2 yang berbeda dari kontrol biasa. Tandai hasil S2 yang prediksinya identik sebagai kontrol berulang, bukan eksperimen independen. Source yang sesuai belum membuktikan identitas runtime lama tanpa executed notebook/checkpoint yang cocok.

Bandingkan RMSE dan MAE, jumlah dalam±1/±2/±5poin, error per jawaban, bias, p90/p95/max error, serta QWK/Pearson/Gwet AC2. RMSE memberi penalti lebih besar pada error besar; hitungan toleransi menghitung banyaknya prediksi dekat. Laporkan tradeoff jika kedua ukuran tidak memilih model yang sama. Semua error memakai skor kontinu tanpa clipping; clipping/konversi kategori hanya untuk agreement.
