# E4 konteks pair · tiga input · LR S3 5e-6 · CPU

Jalankan `notebooks/experiments/AES_300_E4_Tiga_Input_CPU.ipynb` dari atas, unggah `fix_dataset_300.xlsx` jika diminta. Input X adalah `soal`, `response_text`, `jawaban_referensi`; label y adalah `rater`. Label guru tidak dimasukkan ke tokenizer atau encoder. Semua S1/S2/S3 membaca tiga teks; seluruh model dilatih ulang pada folder terpisah `MyDrive/AES_300_E4_Tiga_Input_CPU_Privat`.

Pilihan LR pengguna: encoder RoBERTa S1=1e-5, S3=5e-6; head dan proyeksi=1e-4. E4 awal memakai LR S3=1e-5 dan konteks tambahan hanya di RoBERTa S3. Varian ini memperluas input ke seluruh skenario dan memperkecil LR S3. Konfigurasi model/input/LR yang dihasilkan sama dengan E6 tiga input yang diberikan sebelumnya; label file E4 menunjukkan permintaan asal konteks pair, bukan bukti metode baru atau hasil independen. Nama E6 2.0 disediakan untuk hasil pengulangan tiga seed, bukan notebook ini.

Teks A = soal + referensi; teks B = jawaban siswa. Kedua tokenizer memasukkan special token pasangan sendiri. Konteks maksimal192token, soal maksimal64token; window RoBERTa512/BGE1024 dan overlap128. Konteks diulang per window sehingga seluruh jawaban tercakup; pemotongan konteks dilaporkan. RoBERTa memakai mean CLS antar-window; BGE memakai mean CLS lalu L2 dan tetap frozen. S1 head linear768→1; S2 head MLP1024→256→1; S3 LayerNorm RoBERTa + proyeksi BGE256 + concat1024 + MLP256→1.

CPU float32 dua thread, seed42/split_seed2026, development/test80/20, lima fold pada development, maksimal25epoch/fold, patience5, microbatch1/batch efektif8. Epoch refit ditetapkan dari CV, bukan test. Autosave dua slot A/B per fold/refit tanpa Drive API atau auto-delete. Hasil lama tidak perlu dihapus. Jalankan notebook yang sama dari atas pada runtime baru untuk melanjutkan progres yang cocok. Lima laporan diekspor sebagai `Hasil_AES_E4_Tiga_Input_CPU.zip`. Prediksi baru memerlukan `NEW_QUESTION`, `NEW_REFERENCE`, `NEW_ANSWER`; label baru tidak diperlukan.

Kode mengikuti jalur tiga input yang telah diuji, diturunkan dari source bersih E6 tiga input pada commit8380355. Builder tidak membaca notebook E6 yang kemudian disimpan ulang oleh pengguna di Colab. Dua salinan notebook baru dibuat sama persis; source/model E4/E6 lama tidak diubah.
