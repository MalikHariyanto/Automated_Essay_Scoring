Perilaku yang diperiksa

  • Builder deterministik, identitas kode sah, mirror sama, semua notebook lama tidak berubah.
  • Keanggotaan development/test/lima fold sesuai pembagi diagnosis lama pada fixture yang sama.
  • Mengubah label outer validation dan test tidak memengaruhi seleksi inner alpha. Mengubah label test tidak mengubah grid seleksi, OOF, alpha final atau koefisien final.
  • Fold yang mencampurkan test atau gagal membagi development ditolak. Prediksi OOF dan test berjumlah tepat sesuai anggota partisinya.
  • Model NPZ tanpa pickle dapat dimuat kembali dan mereproduksi prediksi test. RMSE/MAE/toleransi dihitung dari error kontinu, termasuk prediksi di luar0–100.
  • Lima Excel, sheet OOF/test terpisah, checksum arsip, serta teks Excel literal agar respons tidak dieksekusi sebagai formula.
  • Seluruh24cell kode dijalankan berurutan melalui kernel Jupyter dan worker numerik, termasuk ekstraksi encoder frozen acak, nested CV, refit, test fixture dan ekspor. Encoder fixture tidak mempunyai token respons yang terlewat.
  • Empat pemeriksaan diagnosis readout terdahulu tetap lulus, termasuk transformasi train-only dan resume checkpoint MLP; diagnosis lama tidak diganti menjadi eksperimen final.

Pengujian tidak membuktikan performa checkpoint pretrained, kondisi GPU Colab pengguna, kesamaan keanggotaan dataset asli yang belum dimuat dalam run ini, atau bahwa Ridge mengalahkan S2. Kesimpulan itu menunggu ZIP hasil asli dan audit berpasangan terhadap prediksi historis.
