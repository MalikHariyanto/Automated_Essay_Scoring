# Salinan notebook untuk tautan lama

Folder ini dipertahankan karena sejumlah tautan Colab menggunakan `aes-learning/notebooks/`. **Jalur utama adalah [notebooks](../notebooks/README.md)**; mulai dari katalog di sana.

Saat penataan, mirror disamakan dengan jalur utama. Empat mirror yang sebelumnya berbeda dipertahankan di [arsip varian](../notebooks/archive/README.md), tanpa output eksekusi. Tidak ada sumber lama yang sengaja dibuang untuk menyamakan salinan.

Untuk perubahan selanjutnya, perbarui notebook utama dan mirror yang masih dibagikan bersama-sama. Jangan melatih atau mengisi skor/data pribadi pada notebook publik.
